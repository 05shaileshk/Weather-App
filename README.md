# Weather-App
🌤️ SkyPulse - Modern & Responsive Weather App
SkyPulse is a clean, sleek, and fully responsive weather web application built using HTML5, CSS3, JavaScript (ES6+), and GSAP Animations. It allows users to search real-time weather information for any city or country worldwide using the OpenWeatherMap API.

✨ Features
🌍 Global Search: Get live weather updates for any city or country across the globe.

🎨 Modern Glassmorphic UI: Designed with a dark-themed glassmorphism UI, smooth hover effects, and glowing neon accents.

⚡ GSAP Powered Animations: Interactive entrance animations and smooth reveal transitions on search using GSAP.

📱 Fully Responsive Layout: Seamlessly adapts across all screen sizes—desktops, tablets, and mobile devices.

📊 Comprehensive Weather Stats: Displays key metrics including:

Real-time Temperature & Weather Conditions

Wind Speed

Humidity Percentage

Visibility Distance

Atmospheric Pressure

🏷️ Quick-Access Popular Cities: Instant 1-click weather fetch for top global destinations.

🧹 Auto-Clear Search Field: Input bar automatically refreshes after submitting a query for a seamless user experience.

🛠️ Tech Stack & Resources
Frontend: HTML5, CSS3 (Flexbox & CSS Grid)

Logic & API: JavaScript (Async/Await Fetch API)

API Provider: OpenWeatherMap API

Animations: GSAP (GreenSock Animation Platform)

Icons & Fonts: FontAwesome 6, Google Fonts (Poppins)
